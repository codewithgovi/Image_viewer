# Image Viewer

A simple and clean **React-based Image Viewer** application that
allows users to browse images, search through collections, manage
favorites, and view/edit profile information. This project demonstrates
component-based UI design, state management, reusable common components,
and organized folder structure in React.


## Features

###  *User Authentication*

* Login screen with form validation 
* Simple username/password entry

###  *Home Screen*

* Displays images from static API files (`Apidata1.js`,`Apidata2.js`) 
* Like / Unlike functionality 
* Search bar to filter images 
* Responsive layout

### *Profile Page*

* Displays user details
* Editable sections 
* Shows user uploaded or liked images

### *Search & Controller Components*

* Reusable search bar component 
* Controller for managing data flows


##  Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5, CSS3\*\*
* Icons & static assets



## Installation & Setup

git clone https://github.com/codewithgovi/Image_viewer.git || 
cd Image_viewer || npm install || npm start 

Runs on: http://localhost:3000



## Summary

This project is designed to demonstrate:

* Clean React folder structure 
* Component reusability 
* Basic user authentication UI 
* Handling static JSON-like data 
* Routing between screens 
* Image listing and search filtering 
* Using custom assets and icons

Image Viewer is a simple and clean React application that allows users to browse images, search through collections, and manage basic profile information. It includes a login screen, home page with image listings, reusable common components, and a structured folder layout for easy scalability. The project demonstrates React component design, state handling, and UI organization using custom assets, icons, and helper modules.
